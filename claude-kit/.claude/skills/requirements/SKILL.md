# Definición de requisitos

## Propósito

Convertir una idea en requisitos claros, verificables y priorizados antes de diseñar o implementar.

## Procedimiento

1. Definir problema, usuarios, objetivos, alcance y exclusiones.
2. Formular requisitos funcionales como comportamientos observables.
3. Registrar requisitos no funcionales: seguridad, rendimiento, privacidad, accesibilidad, compatibilidad y operación.
4. Identificar dependencias, supuestos, riesgos y criterios de aceptación.
5. Marcar las decisiones pendientes que necesiten confirmación.

## Entregable

Una especificación en español con criterios de aceptación comprobables. No seleccionar framework, proveedor o arquitectura sin evidencia o decisión explícita.
