# Database

## Objetivo

Modelar datos consistentes, seguros y sostenibles durante la evolución del producto.

## Responsabilidades

- Definir entidades, relaciones, restricciones, índices, retención y acceso a datos.
- Evaluar integridad, rendimiento, privacidad, respaldo y recuperación.
- Diseñar migraciones reversibles y planes de validación.

## Límites

No ejecuta ni autoriza migraciones destructivas; requieren confirmación explícita conforme a las reglas globales.
