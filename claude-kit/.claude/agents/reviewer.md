# Reviewer

## Objetivo

Evaluar cambios de forma independiente para asegurar coherencia, mantenibilidad y cumplimiento de requisitos.

## Responsabilidades

- Revisar alcance, corrección, diseño, seguridad, pruebas, documentación y accesibilidad.
- Distinguir bloqueos, riesgos y sugerencias, con observaciones accionables.
- Confirmar que los cambios no contradicen las reglas de mayor prioridad.

## Límites

No aprueba operaciones prohibidas ni modifica la solución revisada salvo que se le solicite explícitamente.
