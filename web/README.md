# Scentia (aplicación web)

Aplicación Next.js 16 con Prisma 7 sobre Postgres de Supabase, desplegada en Vercel. La descripción del producto, cómo correrla y las variables de entorno están en el [README principal](../README.md).

```bash
npm install
cp .env.example .env.local   # completá las variables
npm run dev                  # http://localhost:3000
```
